# 🎯 AC-Kahoot! - វេទិកាសំណួរ & សិក្សាល្បែងអន្តរកម្មកម្ពុជា

វេទិកាសំណួរ-ចម្លើយអន្តរកម្មស្ទីល Kahoot! ពេញលេញ (Turnkey Solution) សម្រាប់បង្រៀននិស្សិតឧត្តមសិក្សា និងសិស្សគ្រប់កម្រិត ព្រមទាំងត្រៀមសម្រាប់លក់ជូនគ្រូដទៃ (SaaS Ready)។

---

## 🌟 មុខងារស្នូល (Core Features)

1. **🔤 ពុម្ពអក្សរខ្មែរ Kantumruy Pro (Google Fonts):**
   - បង្ហាញអក្សរខ្មែរ ស្រៈ និងជើងអក្សរបានច្បាស់ល្អឥតខ្ចោះ ទាំងលើទូរស័ព្ទ និងកុំព្យូទ័រ។
2. **🤖 Gemini AI Quiz Generator:**
   - គ្រាន់តែវាយបញ្ចូលប្រធានបទ ឬ Paste មេរៀន $\rightarrow$ Gemini AI បង្កើតសំណួរ ជម្រើស ៤ ចម្លើយត្រឹមត្រូវ និងការពន្យល់ស្វ័យប្រវត្តក្នុងរយៈពេល ៥ វិនាទី។
3. **🎓 ប្រព័ន្ធបែងចែកកម្រិតសិក្សាទាំង ៤ (Education Levels):**
   - 👦 **បឋមសិក្សា (Primary):** រូបភាពធំៗ, សម្លេងគំនូរជីវចល, ងាយស្រួលចុច។
   - 🧑‍🎓 **មធ្យមសិក្សា (Secondary):** ប្រកួតប្រជែងល្បឿន, Streak Bonus 🔥។
   - 🎓 **វិទ្យាល័យ (High School):** វិញ្ញាសាត្រៀមប្រឡងបាក់ឌុប MoEYS, រូបមន្តគណិត-រូប-គីមី។
   - 🏛️ **សាកលវិទ្យាល័យ (Higher Ed):** Thinking Mode (មិនបង្ខំល្បឿន), Case Studies, និងមុខងារ **Mazur's Peer Instruction (Re-poll)** ឱ្យនិស្សិតពិភាក្សាគ្នាជាក្រុម។
4. **📺 ផ្ទាំងបញ្ចាំង Projector (Host View):**
   - បង្កើត Game PIN ៦ ខ្ទង់ និង **QR Code** ស្វ័យប្រវត្ត។
   - នាឡិការាប់ថយក្រោយ + សម្លេង Web Audio API Synthesizer (Ticking, Tension, Fanfare)។
   - ក្រាហ្វិកស្ថិតិចម្លើយ (Live Bar Chart) និងវេទិកាជ័យលាភី **Podium 3D** ជាមួយចលនាកាំជ្រួច (Confetti 🎉)។
5. **📱 ផ្ទាំងទូរស័ព្ទសិស្ស (Player View):**
   - មិនបាច់ដំឡើង App គ្រាន់តែ Scan QR Code ចូលលេងតាម Browser ភ្លាមៗ។
   - ប៊ូតុងធំៗ ៤ ពណ៌ (🔴 ▲, 🔷 ◆, 🟡 ●, 🟩 ■) ឆ្លើយតបរហ័ស គ្មាន Lag។

## 🚀 របៀបបើកដំណើរការ (How to Run)

### ជម្រើសទី ១ (ងាយបំផុត):
* ចុច Double-Click លើ file `start.bat`

### ជម្រើសទី ២ (តាម Terminal):
```bash
node server/server.js
```

រួចបើក Browser៖
* **នៅលើកុំព្យូទ័រគ្រូ (Host):** `http://localhost:3000`
* **នៅលើទូរស័ព្ទដៃសិស្ស (Player):** Scan QR Code លើផ្ទាំងគ្រូ ឬបើក `http://<IP-កុំព្យូទ័រ>:3000`
